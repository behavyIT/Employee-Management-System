# Employee Management System

Консольное приложение на C++ для управления базой данных сотрудников.

## Возможности

- Загрузка базы данных из `.txt` файла
- Вывод списка сотрудников
- Добавление и удаление записей
- Сортировка по ФИО
- Сортировка по отделу и должности
- Сортировка по табельному номеру
- Поиск сотрудников по дате приёма
- Формирование перечня должностей и подсчёт сотрудников по каждой должности
- Сохранение данных и результатов работы в файл
- Реализация конструктора копирования и оператора присваивания для всей иерархии классов

## Технологии

- C++
- Работа с файлами (`fstream`)
- Динамическая память
- ООП
- Git

## Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/behavyIT/Employee-Management-System.git
cd Employee-Management-System
Скомпилируйте проект:

g++ -std=c++17 main.cpp masA.cpp masB.cpp masC.cpp structures.cpp -o EmployeeManagementSystem

Запустите программу:

./EmployeeManagementSystem

После запуска выберите пункт:

1. Загрузить из файла (masA)

и введите:

h.txt

```

Формат базы данных

Каждая запись в файле должна иметь следующий формат:

ФИО|Дата приема|Табельный номер|Номер отдела|Должность|Оклад

Пример:

Иванов Иван Иванович|15.03.2020|1001|5|Инженер-программист|95000.00
