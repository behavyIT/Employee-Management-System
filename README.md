# Employee-Management-System
Система управления базой данных сотрудников. Реализована на языке C++. База данных загружается локально через файл формата .txt.
Консольное приложение на C++ для управления базой данных сотрудников.
Реализована возможность загружать базу данных через файл .txt
Есть возможности добавлять сотрудников, удалять, также есть различные сортировки базы данных и поиск.
Также реализованы конструкторы копирования и операторы присваивания
